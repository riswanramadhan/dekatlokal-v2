# DekatLokal V3 Content Data Model

## Foundational Modules

The platform has exactly eight foundational modules:

1. Digitalisasi UMKM
2. Branding UMKM
3. Produk dan Kemasan
4. Konsistensi Promosi
5. Marketplace dan Kanal Penjualan
6. Operasional dan Keuangan Dasar
7. Legalitas Usaha
8. Komitmen dan Growth Mindset

Each module has:

- slug, title, outcome, icon, theme
- four lesson summaries
- generated lesson screens from curriculum content
- one practical task
- one Business Asset output
- 8-question post-test
- corrective review per weak topic
- completion badge
- legal/production note when needed

## Assignments

Digital Checkup assigns exactly three modules. Active dashboard and progress views emphasize only those three; the other five may appear as locked/reference content and cannot distract from the active path.

## Claim Preview

`CheckupClaimPreview.recommendedModules` contains the authoritative three modules. `distractorModules` contains three plausible alternatives for recall. Recall choices never change the official assignment.

## Asset Registry

Registry entries include key, src, alt, usage, license, attribution, and type. Current V3 assets are local brand files, local illustrations, and generated local sounds.
